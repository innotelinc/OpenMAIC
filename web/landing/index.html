OpenMAIC — Generated multi-agent classrooms, in the browser.

A classroom host that turns a course into generated multi-agent lessons: slides, quizzes, interactive HTML simulations and project work. OnTrak Class runs it behind the family sign-in and links a cohort to its classroom.

A generated lesson is a wall of text.

Agents teach, quiz and run the simulation, so the learner works through it.

Authoring a classroom by hand does not scale.

A course specification generates the classroom and its checks.

Progress lives in the classroom.

Completion is handed to the record of record rather than kept as a second one.
